# Arabic store listing (ar)

Google Play: Play Console → Grow users → Store presence → Main store listing → Manage translations → Add your own translations → **Arabic – ar**, then paste each block.
App Store: App Store Connect → your app → the language menu at the top right → add **Arabic**, then paste the App Store blocks.

Screenshots can stay in English for now. Character limits were checked by `scripts/check-store-listings.mjs`.

## Google Play

### App name (max 30)

```
Muslimo: تعلّم الإسلام يوميًا
```

### Short description (max 80)

```

### Full description (max 4,000)

```
تعلّم الإسلام في دقائق كل يوم، بمتعة اللعب. تطبيق مسابقات إسلامية للأطفال والشباب والكبار.

يحوّل Muslimo تعلّم الإسلام إلى دروس قصيرة تشبه الألعاب. أجب عن الأسئلة، وحافظ على سلسلتك اليومية، واجمع النقاط والتمر، وشاهد طريقك يُفتح خطوة بخطوة. كل درس معه مصدره، لتقرأ المزيد في Quran.com وSunnah.com وعند العلماء الموثوقين.

ماذا ستتعلّم
• الإيمان والسلام والأذكار اليومية وأساسيات يحتاجها كل مسلم
• الوضوء خطوة بخطوة، ثم الصلاة من تكبيرة الإحرام إلى التسليم
• القرآن والتفسير: سورة بعد سورة مع المعنى
• قصص الأنبياء: من آدم عليه السلام إلى محمد ﷺ بالترتيب
• الصحابة: الخلفاء الراشدون وغيرهم من الصحابة
• الآداب: الصدق والرحمة وبر الوالدين وغير ذلك
• الصيام والزكاة والحج ويوم القيامة

تعلّم بطريقة تثبت
• دروس قصيرة تناسب الاستراحة أو ما بعد الصلاة
• الأسئلة التي أخطأت فيها تعود حتى تحفظها
• شرح سهل بعد كل إجابة

حافظ على حماسك
• سلسلة يومية ونقاط وتمر وصناديق مكافآت
• منافسة أسبوعية مع العائلة والأصدقاء ومعارك أسئلة
• ادعُ صديقًا برمزك وتحصلان معًا على التمر
• تذكيرات طريفة من الجمل (يمكن إيقافها في أي وقت)

يعمل التطبيق بالعربية والإنجليزية والبنغالية والأردية. التنزيل والدروس الأساسية مجانية.

Muslimo وسيلة للتعلّم وليس خدمة فتوى. اسأل عالمًا موثوقًا عن الأحكام التي تخصّك. إن وجدت خطأ فراسلنا، وسنراجعه إن شاء الله.
```

## App Store

### Name (max 30)

```

```

### Subtitle (max 30)

```
مسابقة القرآن والحديث والسيرة
```

### Keywords (max 100 bytes, comma separated, no spaces)

Apple counts this field in bytes, and each letter of this script takes 2 or 3, so it holds fewer words. Words in the name and subtitle are already indexed. A few English words are kept because many people search in English.

```
صلاة,وضوء,دعاء,رمضان,أذكار,الصحابة,أطفال,quran,islam,muslim
```

```
